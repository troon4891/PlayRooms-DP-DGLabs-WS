### manifest.yaml Schema Verification

Open `manifest.yaml` and verify:

```yaml
# Required fields present:
name: dglab-ws
type: device-provider
providerApiVersion: 1
requirements:
  network: true
  bluetooth: false
  serial: false

# AI interaction policy:
aiInteraction:
  allowed: true
  defaultEnabled: false

# Risk flags present:
riskFlags:
  - type: "electrical-stimulation"
    severity: high
  - type: "requires-physical-safety-gear"
    severity: medium
  - type: "network-dependent"
    severity: low

# Settings present:
settings:
  wsUrl:
    required: true
  logLevel:
    type: select
    options: [debug, info, warn, error]
```

- [ ] All above fields are present with correct values
- [ ] `bluetooth: false` — this is WebSocket, not BLE (critical — wrong value here would cause loader errors)
- [ ] `network: true` — the relay server connection is a network requirement
- [ ] `defaultEnabled: false` for AI interaction — e-stim must not be AI-controlled by default
